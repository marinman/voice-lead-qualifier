## What is LiveKit?
keywords: what is livekit, what does livekit do, what is this, who are you
LiveKit is an open source platform for building realtime voice, video, and AI agent applications. Developers use the LiveKit Agents framework to build voice agents, and LiveKit Cloud to run the realtime transport at scale.

## How does pricing work?
keywords: price, pricing, cost, how much, free tier, expensive
At a high level, LiveKit Cloud has a free tier to get started, then usage-based pricing as you scale, with plans for larger teams. The open source server is free to self-host. Exact numbers live on the pricing page, and a human can walk through volume pricing.

## Where are the docs?
keywords: docs, documentation, guide, tutorial, get started, quickstart
The docs live at docs.livekit.io. The voice AI quickstart gets a working agent running in a few minutes.

## Is it open source?
keywords: open source, open-source, github, self host, self-host
Yes. The LiveKit server, the Agents framework, and the client SDKs are open source on GitHub. You can self-host or use LiveKit Cloud.

## Which models can I use?
keywords: models, which llm, openai, speech to text, text to speech, stt, tts
The Agents framework is model-agnostic. You can plug in speech-to-text, LLM, and text-to-speech providers through plugins or LiveKit Inference.

## Does it work with phone calls?
keywords: phone, telephony, sip, call center, pstn
Yes. LiveKit supports SIP telephony, so the same agent can answer or place phone calls.
